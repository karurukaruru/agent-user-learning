# Agent User Learning（AUL）

**智能体用户学习：让智能体逐渐了解用户，并调整帮助方式。**

[English](README.md) · [事件协议](skills/agent-user-learning/references/protocol.md) · [接入方式](skills/agent-user-learning/references/integration.md)

AUL 是独立的开源项目，可以接入不同的智能体、产品和编程助手，不依赖 OpenWoven 或某个模型。

它学习用户主动分享的资料、兴趣、喜欢与不喜欢、目标、习惯，以及希望怎样被帮助。根据当前任务选择相关信息，用于调整回答、例子、建议和执行方式；用户纠正时，及时更新理解。

例如，用户想通过日语 N4、喜欢 City Pop、偏爱简短例题，智能体可以据此安排练习、选择例子。用户后来表示“学习时不要背景音乐”，这项偏好只在学习场景生效，其他场景仍可保留原有喜好。

## 两个核心部分

| 部分 | 记录什么 | 用途 |
| --- | --- | --- |
| 用户理解 | 明确分享的资料、兴趣、喜好、目标、习惯、限制、临时状态 | 理解用户的需求和背景 |
| 帮助方式 | 回答长度、例子形式、解释顺序、工作流程等偏好 | 调整智能体的具体行为 |

记忆提供保存能力，AUL 进一步提供证据、确认条件、纠正、遗忘和按场景选择上下文。真正如何使用这些信息，由接入的智能体决定。

## 快速试用

需要 Python 3.11 或更新版本，在项目目录执行：

```sh
python -m pip install .
python examples/user_learning_demo.py
```

示例使用虚构用户和内存数据库，无需 API Key，也不调用网络。项目提供 Python SDK、命令行，以及可复制到 Codex、Claude Code、OpenCode 的 Skill。安装目录见英文说明。

## 学习规则

- 用户明确表达或纠正的信息立即生效；推测的兴趣、习惯等需要两个不同会话、两个独立来源的重复证据。
- 身份和限制只接受明确的用户证据，不从几次聊天推断人格或敏感身份。
- 当前状态必须带有效期；临时忙碌不会自动变成永久特点。
- 场景标签由接入方选择；更具体场景可覆盖一般偏好。
- 能查看、解释、纠正和遗忘；忘记一项喜好会删除同场景该项目喜欢／不喜欢的历史，避免旧值恢复。
- 以用户为单位隔离数据库；保存简短证据和来源，不保存整段对话。

当前是 **0.1.0 可运行原型**，运行时仅依赖 Python 标准库。它不会自行解析聊天，也不会训练模型参数。接入方需要完成用户证据提取、任务场景选择和上下文使用；Skill 安装本身不会自动创建生命周期钩子。

下一步重点是产品和智能体适配器，以及真实交互评估：是否减少重复纠正、是否更好地完成任务，再据此验证用户体验提升。
